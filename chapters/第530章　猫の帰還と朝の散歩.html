第五百三十章　猫ねこgatoの帰還きかんretornoと朝あさmanhã··の散歩さんぽcaminhada

駅えきestacaoまでの道みちcaminhoを歩あるcaminharきながら、四人よにんquatro pessoasは昨日きのうontemの猫ねこgatoの話はなしconversaを続つづcontinuarけていた。「餌えcomida、何なにo queを買かcomprarおうか」「缶詰かんづめlata de comidaと、おやつpetiscoも必要ひつようnecessarioだ」ダンの提案ていあんsugestaoに、ティファが頷うなずassentirいた。「毛布もうふcobertorも忘わすesquecerれちゃだめ」駅えきestacaoの近ちかpertoくには小ちいpequenoさなペットショップぺっとしょっぷpetshopとスーパーすーぱーsupermercadoが並ならalinhadoんでいた。

ペットショップぺっとしょっぷpetshopに入はいentrarると、店員てんいんfuncionarioが笑顔えがおrosto sorridenteで迎むかreceberえた。「何なにo queをお探さがprocurarしですか？」「猫ねこgatoの餌えcomidaを探さがprocurarしてるんです」言いdizerうと、店員てんいんfuncionarioは棚たなprateleiraの方ほうdirecaoを指さapontarした。「あちらlaです」棚たなprateleiraには様々さまざまvariosな種類しゅるいtipoの餌えcomidaが並ならalinhadoんでいた。「多おおmuitoくて選えらescolherべないわね」舞が困こまdificilったような顔かおrostoを見みverせた。

「これesteはどう？」キャミィが手てmaoに取とpegarったのは、高たかcaroいブランドぶらんどmarcaの缶詰かんづめlata de comidaだった。「栄養えいようnutricaoが良よbomさそう」「高たかcaroいわよ」舞が指摘してきapontarすると、キャミィは平気へいきtranquiloな顔かおrostoで答こたresponderえた。「猫ねこgatoのためだ」「本当ほんとうverdadeiroに猫ねこgatoのため？」ダンの言葉ことばpalavraに、キャミィは少すこum poucoし照てenvergonhadoれくさそうに答こたresponderえた。「……一応いちおうpor via das duvidasだ」

「私わたしeuも選えらescolherぶ」ティファが別べつoutroの棚たなprateleiraからおやつpetiscoを取とpegarった。「可愛かわいfofoい形かたちformatoね」魚さかなpeixeの形かたちformatoをしたおやつpetiscoを見みverて、ティファは嬉うれfelizしそうな顔かおrostoを見みverせた。「猫ねこgatoが喜よろこfelizぶわ」「多おおmuitoく買かcomprarうな」ダンが注意ちゅういcuidadoすると、ティファは少すこum poucoし不満ふまんinsatisfeitoそうな顔かおrostoを見みverせた。「少すこum poucoしくらい……」最後さいごultimoに、四人よにんquatro pessoasは毛布もうふcobertorを選えらescolherんだ。小ちいpequenoさくて持もcarregarち運はこtransportarび易やすfacilい物ものobjetoを選えらescolherんだ。

店みせlojaを出でsairると、外そとforaは少すこum poucoし暖あたたquenteかくなっていた。「日ひsolが出でsairて来きvirた」言いdizerうダンに、舞は頷うなずassentirいた。「昨日きのうontemより歩あるcaminharき易やすfacilいわ」家いえcasaへと向むdirecionar-seかう道みちcaminhoで、昨日きのうontemの猫ねこgatoが姿すがたfiguraを現あらわaparecerした。「猫ねこgato！」ティファが声こえvozを上あelevarげると、猫ねこgatoは少すこum poucoし驚おどろsurpreender-seいた様子ようすaparenciaで四人よにんquatro pessoasを見みverつめた。

「覚おぼlembrarえてる？」言いdizerうと、猫ねこgatoは少すこum poucoし近ちかpertoづいて来きvirた。「昨日きのうontemも来きvirた猫ねこgatoだ」ダンが言いdizerうと、キャミィが頷うなずassentirいた。「覚おぼlembrarえてるわ」四人よにんquatro pessoasは猫ねこgatoを囲かこcercarんだ。猫ねこgatoは人ひとpessoaに慣なacostumar-seれているようで、甘あまdocilえて来きvirた。「可愛かわいfofoい」ティファが猫ねこgatoの頭あたまcabecaを撫なacariciarでた。

「餌えcomidaを持もtrazerって来きvirたのよ」舞が言いdizerうと、猫ねこgatoは鳴なmiarいて答こたresponderえたようだ。「分わsaberかったって言いdizerってる」ダンが笑わらrirうと、皆みなtodosが笑わらrirった。「今いまagora、開あabrirける？」「家いえcasaに帰かえvoltarってからにしよう」キャミィが言いdizerうと、猫ねこgatoは少すこum poucoし不満ふまんinsatisfeitoそうな顔かおrostoを見みverせた。

家いえcasaに着つchegarくと、四人よにんquatro pessoasは買かcomprarった物ものobjetoを置おcolocarいた。「早速さっそくimediatamente、開あabrirけよう」ティファが言いdizerうと、キャミィが頷うなずassentirいた。「皿さらpratoを持もtrazerって来きvirる」台所だいどころcozinhaから戻もどvoltarって来きvirたキャミィは、小ちいpequenoさな皿さらpratoを持もtrazerっていた。「綺麗きれいlimpoに洗あらlavarった？」言いdizerう舞に、キャミィは少すこum poucoし照てenvergonhadoれくさそうに答こたresponderえた。「……一応いちおうpor via das duvidasだ」

缶詰かんづめlata de comidaを開あabrirけると、美味おいsaborosoしそうな匂におcheiroいが広ひろespalharがった。「美味おいsaborosoしそう」ティファが言いdizerうと、猫ねこgatoは鳴なmiarいて答こたresponderえた。皿さらpratoに餌えcomidaを入いcolocarれて、外そとforaに出でsairた。猫ねこgatoは美味おいsaborosoしそうに食たcomerべていた。「美味おいsaborosoしい？」言いdizerうティファに、猫ねこgatoは鳴なmiarいて答こたresponderえたようだ。

「毛布もうふcobertorも置おcolocarこう」ダンが言いdizerうと、猫ねこgatoは少すこum poucoし警戒けいかいalertaした様子ようすaparenciaを見みverせた。「大丈夫だいじょうぶtudo bemだ」言いdizerいながら、ダンは毛布もうふcobertorを置おcolocarいた。猫ねこgatoは少すこum poucoし経たpassarつと、毛布もうふcobertorの上うえcimaに乗のsubirった。「暖あたたquenteかそう」言いdizerう舞に、皆みなtodosが頷うなずassentirいた。

「名前なまえnomeは何なにo queにしようか」ティファが言いdizerうと、四人よにんquatro pessoasは顔かおrostoを見合みあolhar mutuamenteわせた。「茶色ちゃいろmarromと白しろbrancoだから……」「茶々ちゃちゃChachaは？」「白しろbrancoも入はいestarってるから……」「白太しろたShirotaは？」「猫ねこgatoらしくない」言いdizerうダンに、ティファは少すこum poucoし不満ふまんinsatisfeitoそうな顔かおrostoを見みverせた。「何なにo queが良よbomいの？」「猫ねこgatoらしい名前なまえnomeだ」

「小町こまちKomachiは？」「古ふるvelhoすぎる」「虎とらToraは？」「大おおgrandeきすぎる」「玉たまTamaは？」「普通ふつうcomumすぎる」四人よにんquatro pessoasは中々なかなかdificil決きdecidirまらなかった。「取とpegarり合あmutuamenteえず、一旦いったんpor enquanto猫ねこgatoでいい」キャミィの提案ていあんsugestaoに、三人さんにんtres pessoasが頷うなずassentirいた。「後あとdepoisで考かんがpensarえよう」猫ねこgatoは餌えcomidaを食たcomerべ終おterminarえると、毛布もうふcobertorの上うえcimaで丸まるenrolar-seくなった。

「可愛かわいfofoい」ティファが言いdizerうと、猫ねこgatoは少すこum poucoし目めolhoを開あabrirけた。「寝ねdormirてしまった」言いdizerう舞に、皆みなtodosが笑わらrirった。「明日あしたamanhaも来きvirるかな」「来きvirるだろう」ダンが答こたresponderえると、キャミィが少すこum poucoし嬉うれfelizしそうな顔かおrostoを見みverせた。「……一応いちおうpor via das duvidas、餌えcomidaを多おおmuitoく買かcomprarっておこう」

翌朝よくあさmanha seguinte、目めolhoを覚さdespertarますと、外そとforaは晴はensolaradoれていた。「天気がいいtempo bom」言いdizerう舞に、皆みなtodosが頷うなずassentirいた。「散歩さんぽcaminhadaに行いirこう」「猫ねこgatoも探さがprocurarせる」ティファが言いdizerうと、四人よにんquatro pessoasは外出がいしゅつsaidaの準備じゅんびprepararを始はじcomecarめた。少すこum poucoし厚あつgrossoい服ふくroupaを着きvestirて、家いえcasaを出でsairた。

家いえcasaの前まえfrenteの通とおpassagemりを歩あるcaminharくと、昨日きのうontemの猫ねこgatoが姿すがたfiguraを現あらわaparecerした。「猫ねこgato！」ティファが声こえvozを上あelevarげると、猫ねこgatoは鳴なmiarいて答こたresponderえた。「覚おぼlembrarえてた」言いdizerう舞に、猫ねこgatoは近ちかpertoづいて来きvirた。「散歩さんぽcaminhadaに付つacompanharいて来きvirる？」言いdizerうダンに、猫ねこgatoは鳴なmiarいて答こたresponderえた。

四人よにんquatro pessoasと一匹いっぴきum animalの猫ねこgatoは、朝あさmanhã··の散歩さんぽcaminhadaを始はじcomecarめた。猫ねこgatoは四人よにんquatro pessoasの前まえfrenteを歩あるcaminharいたり、後うしtrasろを付つacompanharいて来きvirたりした。「元気げんきenergiaだ」言いdizerうティファに、猫ねこgatoは鳴なmiarいて答こたresponderえた。公園こうえんparqueに着つchegarくと、猫ねこgatoは芝生しばふgramadoの上うえcimaで転ころrolarがり始はじcomecarめた。「楽たのdivertidoしそう」言いdizerう舞に、皆みなtodosが笑わらrirった。

「猫ねこgato、私達わたしたちnosに慣なacostumar-seれた」ティファが言いdizerうと、キャミィが頷うなずassentirいた。「一応いちおうpor via das duvidas、餌えcomidaを持もtrazerって来きvirた価値かちvalorはあった」言いdizerいながら、キャミィは少すこum poucoし嬉うれfelizしそうな顔かおrostoを見みverせた。「本当ほんとうverdadeiroに猫ねこgatoのため？」ダンの言葉ことばpalavraに、キャミィは少すこum poucoし照てenvergonhadoれくさそうに答こたresponderえた。「……一応いちおうpor via das duvidasだ」

公園こうえんparqueを出でsairて、家いえcasaへと向むdirecionar-seかう道みちcaminhoで、猫ねこgatoは少すこum poucoし疲つかcansadoれた様子ようすaparenciaを見みverせた。「帰かえvoltarりたい？」言いdizerう舞に、猫ねこgatoは鳴なmiarいて答こたresponderえた。家いえcasaの前まえfrenteに着つchegarくと、猫ねこgatoは毛布もうふcobertorの上うえcimaに乗のsubirった。「昨日きのうontemの場所ばしょlugarを覚おぼlembrarえてる」言いdizerうティファに、皆みなtodosが頷うなずassentirいた。

「今日きょうhojeは何なにo queをするfazer？」「本屋ほんやlivrariaに行いirこう」ダンが言いdizerうと、三人さんにんtres pessoasが頷うなずassentirいた。「駅えきestacaoの近ちかpertoくにあった本屋ほんやlivrariaね」「喫茶店きっさてんcafeも併設へいせつanexoされてるんだって」言いdizerうキャミィに、ティファが嬉うれfelizしそうな顔かおrostoを見みverせた。「楽たのdivertidoしみ」猫ねこgatoは毛布もうふcobertorの上うえcimaで丸まるenrolar-seくなって、四人よにんquatro pessoasの姿すがたfiguraを見送みおくdespedir-se com os olhosっていた。

※ キャミィの「一応」は、彼女なりの照れ隠しの表現として定着しつつある。

※ 猫との散歩は、四人の日常に新しい温もりを加えた。

※ 本屋への言及は、次章への自然なつなぎとして機能している。
