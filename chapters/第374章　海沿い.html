第三百七十四章　海沿いうみぞいbeira-mar

二日目ふつかめsegundo diaの朝あさmanhãは、前日ぜんじつdia anteriorとは違うちがうdiferente空気くうきarで始まったはじまったcomeçou。山道やまみちestrada de montanhaの緊張きんちょうtensãoが抜けてぬけてdissipada、体からだcorpoが旅たびviagemのリズムritmoに慣れてきたなれてきたse acostumou証拠しょうこprovaに、四人よにんos quatroとも出発前しゅっぱつまえantes de partirの会話かいわconversaが昨日よりきのうよりdo que ontem少しすこしum pouco長かったながかったmais longa。海岸かいがんlitoralへ向かうむかうem direção aoルートrotaは平坦へいたんplanaで、空そらcéuは雲一つないくもひとつないsem uma nuvem青あおazulだった。

海沿いうみぞいà beira-marの直線ちょくせんretaに出たでたchegaram瞬間しゅんかんinstante、キャミィCammyはアクセルを開けたあくせるをあけたabriu o acelerador。音おとsomが変わりかわりmudou、景色けしきpaisagemが横に流れるよこにながれるpassou para o lado速さはやさvelocidadeで、後ろうしろatrásに乗るのるsentadaティファTifaの体からだcorpoが少しすこしum pouco後ろへうしろへpara trás引かれたひかれたpuxado。それissoだけで、ティファTifaは笑い声を上げたわらいごえをあげたsoltou uma risada。

「速いはやいrápido！」声こえvozが風かぜventoに混じってまじってmisturada ao消えたきえたdesapareceu。キャミィCammyは前を向いたまままえをむいたままde frenteだったが、口元くちもとcanto da bocaがわずかにlevemente動いたうごいたse moveu。さらにainda maisアクセルを開けたあくせるをあけたabriu o acelerador。ティファTifaの笑い声わらいごえrisadaがもう一度もういちどmais uma vez上がったあがったsubiu。今度こんどdesta vezはよりainda mais高くたかくalto、よりainda mais長くながくlongo。

隣となりao ladoを走るはしるandavaもう一台もういちだいa outra motoでは、舞まいMaiが片手かたてcom uma mãoでスマホcelularを構えていたかまえていたsegurava。ダンDanが速度そくどvelocidadeを合わせるあわせるajustouと、舞まいMaiはティファTifaとキャミィCammyのバイクmotoに向けてむけてapontando para画面がめんa telaを固定したこていしたfixou。ティファTifaの笑い声わらいごえrisadaは映像えいぞうvídeoの中なかdentroでもはっきりclaramente聞こえたきこえたpodia ser ouvida。

「もっとmais！」ティファTifaが言うというとdisse、キャミィCammyは何も言わずになにもいわずにsem dizer nadaまたde novoアクセルを開けたあくせるをあけたabriu o acelerador。三回目さんかいめpela terceira vezの加速かそくaceleraçãoで、ティファTifaはキャミィCammyの背中せなかcostasに顔を埋めかおをうめenterrou o rostoながら笑い続けたわらいつづけたcontinuou rindo。キャミィCammyは正面しょうめんde frenteを向いたままむいたままcontinuou olhandoで一言ひとことuma coisaだけ言ったいったdisse。「楽しいたのしいestá gostando？」「すごくmuito！」それissoで十分だったじゅうぶんだったera suficiente。

舞まいMaiは映像えいぞうvídeoを止めてとめてparouからダンDanの肩かたombroを軽くかるくde leve叩いたたたいたbateu。「見たみたviu？」「見たみたvi」「キャミィCammy、笑ってたわよわらってたわよestava sorrindo」「知ってるしってるsei」「すごいincrívelことcoisaね」「そうだなそうだなé sim」二人ふたりos doisはしばらくpor um tempoそのaquele事実じじつfatoを静かにしずかにem silêncio味わったあじわったapreciaram。

海岸線かいがんせんlinha costeiraが続くつづくcontinuava中なかenquanto、道みちestradaは海うみmarと並行へいこうparalelaに伸びていたのびていたse estendia。波なみondasの音おとsomが時々ときどきàs vezesエンジンmotorの音おとsomを超えてこえてsuperava届いたとどいたchegava。風かぜventoに塩しおsalの味あじsaborが混じっていてまじっていてmisturado、昨日きのうontemの山やまmontanhaとはまったくcompletamente違うちがうdiferente空気くうきarだった。キャミィCammyは自然しぜんnaturalmenteに速度そくどvelocidadeを落としおとしreduziu、ティファTifaは顔を上げてかおをあげてergueu o rosto水平線すいへいせんhorizonteを見たみたolhou。

「海うみmarだ」ティファTifaが言ったいったdisse。意味いみsentidoはなかったなかったnão haviaが、言わずにいわずにsem dizerはいられなかったいられなかったnão conseguiu ficar。「そうだそうだé」キャミィCammyも同じおなじigual水平線すいへいせんhorizonteを見ながらみながらolhando答えたこたえたrespondeu。二人ふたりas duasの間あいだentreにしばらくpor um tempo沈黙ちんもくsilêncioが続いたつづいたcontinuouが、それissoは空虚くうきょvazioではなく、満ちていたみちていたcheio。

止まるとまるparar場所ばしょlugarはダンDanが事前じぜんcom antecedênciaに調べていたしらべていたpesquisou小さなちいさなpequena砂浜すなはまpraia de areiaだった。人ひとpessoasが少なくすくなくpoucas、駐車ちゅうしゃestacionarできるスペースespaçoもある。バイクmotosを止めてとめてparandoから四人よにんos quatroは砂浜すなはまa praiaに降りたおりたdesceram。砂すなareiaは白くしろくbranca、波なみondasは穏やかでおだやかでcalmas、足跡あしあとpegadasはまだainda少ないすくないpoucas。

舞まいMaiが最初さいしょa primeiraにブーツを脱いだぶーつをぬいだtirou as botas。片足かたあしum péずつ砂すなna areiaに下ろしておろしてcolocou、少しすこしum pouco指先でゆびさきでcom as pontas dos dedos押しておしてpressionandoみてから小さくちいさくbaixinho言ったいったdisse。「柔らかいやわらかいmacia」ティファTifaもすぐlogoに靴を脱いでくつをぬいでtirou os sapatos、その感触そのかんしょくaquela sensaçãoを自分でじぶんでela mesma確かめたたしかめたconfirmou。「温かいあたたかいquente」と言うというとdisse、舞まいMaiは大きくおおきくamplamente頷いたうなずいたassentiu。

キャミィCammyは少しすこしum pouco間を置いてからまをおいてからdepois de uma pausa靴を脱いだくつをぬいだtirou os sapatos。砂すなareiaを一度いちどuma vez踏んでふんでpisando、またde novo踏んでふんでpisando、それからentão何も言わずになにもいわずにsem dizer nada波打ち際なみうちぎわborda das ondasへ向かったむかったfoi。ティファTifaがその後ろをそのうしろをatrás delaついたついたseguiu。二人ふたりas duasは並んでならんでlado a lado砂浜すなはまa praiaを歩きあるきcaminharam、波なみondasの端はしbordaまで来てきてchegando止まったとまったpararam。波なみondaが足首あしくびtornozeloまで来たきたchegouとき、キャミィCammyは動かなかったうごかなかったnão se moveu。冷たいつめたいfriaと言いたそうないいたそうなcomo se quisesse dizer顔かおexpressãoで、でも何もなにもnada言わなかったいわなかったnão disse。ティファTifaが横よこao ladoで笑ってわらってrindo「冷たいつめたいfria？」と聞くときくとperguntou、キャミィCammyは一拍いっぱくum tempo置いてからおいてからdepois de uma pausa「予想よりよそうよりmais do que o esperado」と答えたこたえたrespondeu。

後ろうしろatrásでは舞まいMaiが砂浜すなはまna praiaに腰を下ろしてこしをおろしてse sentou、片膝かたひざum joelhoを立ててたててlevantado海うみo marを見ていたみていたolhava。ダンDanは立ったままたったままde péでカメラcâmeraを持ちもちsegurando、構図こうずcomposiçãoを探していたさがしていたprocurava。四人よにんos quatroがバラバラespalhadasに見えてみえてpareciam、でもmas全員ぜんいんtodasが同じおなじa mesma海うみmarを向いていたむいていたencaravam。

ダンDanはカメラcâmeraを下ろしたおろしたabaixou。それからentãoもう一度もういちどmais uma vez上げたあげたlevantou。今度こんどdesta vezは四人全員よにんぜんいんas quatroが自然にしぜんにnaturalmente入るはいるcabiam角度かくどânguloを見つけていたみつけていたencontrou。波打ち際なみうちぎわà beira das ondasに立つたつem péキャミィCammyとティファTifa、砂すなna areiaに座るすわるsentada舞まいMai、遠くとおくao longeに広がるひろがるse espalhando海うみmarと空そらcéu。誰もだれもninguémポーズを取っていないぽーずをとっていないestava posando。誰もだれもninguémカメラをかめらをpara a câmera意識していないいしきしていないolhava。

シャッターobturadorを切ったきったclicou瞬間しゅんかんinstante、ダンはそのaquela一枚いちまいfotoが何かなにかalgo特別とくべつespecialだと知ったしったsoube。三人さんにんas trêsの表情ひょうじょうexpressãoが全部ぜんぶtodas違うちがうdiferentesのに、どれもcada uma本物だったほんものだったeram autênticas。構図を計算したわけではなくこうずをけいさんしたわけではなくnão calculou a composição、光が良かったわけでもないひかりがよかったわけでもないnem a luz estava perfeita。ただapenas、その場所そのばしょaquele lugarにその瞬間そのしゅんかんaquele instanteに、四人よにんos quatroが揃っていたそろっていたestavam juntosだけのことだった。

舞まいMaiが後ろからうしろからpor trás声を掛けたこえをかけたchamou。「ダンDan、何枚撮ったなんまいとったquantas tirou？」「今はいまはpor agora一枚いちまいuma」「一枚だけいちまいだけsó uma？」「十分じゅうぶんsuficienteだった」舞まいMaiはしばらくpor um tempo黙ってだまってem silêncioそれをisso聞いてきいてouviuから、またde novo海うみo marを向いたむいたvoltou para o mar。「見せてねみせてねme mostra、後であとでdepois」「ああclaro」

波打ち際なみうちぎわà beira das ondasからキャミィCammyとティファTifaが戻ってきたもどってきたvoltaram。キャミィCammyの足あしpéに砂すなareiaがついていてついていてestava grudada、ティファTifaがそれをisso指差したゆびさしたapontou。キャミィCammyは一瞬いっしゅんpor um instante見下ろしてからみおろしてからolhando para baixo、砂を払わずにすなをはらわずにsem tirar a areiaそのままassim mesmo歩き続けたあるきつづけたcontinuou andando。「払わないのはらわないのnão vai tirar？」「後であとでdepois」ティファTifaはそのaquela答えこたえrespostaが気に入ってきにいってgostou、自分もじぶんもela também払わなかったはらわなかったnão tirou。

四人よにんos quatroはしばらくpor um tempo砂浜すなはまna praiaに裸足はだしdescalçasでいたficaram。舞まいMaiが波なみondaに足先あしさきas pontas dos pésを突っ込もうとしてつっこもうとしてtentando meterキャミィにきゃみぃにpara Cammy止められたとめられたfoi parada。「まだainda靴下をくつしたをa meia穿いてるはいてるestá usando」「じゃあentão脱ぐぬぐtiro」「遅いおそいtarde demais」波なみondaはすでにjá来ていたきていたtinha chegado。舞まいMaiは濡れたぬれたmolhada靴下くつしたmeiaを見てみてvendo笑い出したわらいだしたcomeçou a rir。ティファTifaもつられてつられてcontagiada笑いわらいriu、キャミィCammyだけが一人ひとりsozinha「だからpor isso言ったいったdisse」と繰り返したくりかえしたrepetiu。

ダンDanはそれtudo issoを少しすこしum pouco離れてはなれてde longe見ていたみていたobservavaが、カメラcâmeraは上げなかったあげなかったnão levantou。さっきのさっきのa de antes一枚いちまいfotoがあればあればse existe十分じゅうぶんo bastanteだと思っていたおもっていたpensava。三人さんにんas trêsの笑い声わらいごえrisadaと波なみondasの音おとsomが混じってまじってmisturadas、海うみo marの向こうむこうalémへ流れていったながれていったfluíam。それissoは覚えておけるおぼえておけるdá para guardar種類しゅるいtipoの音おとsomだった。

※ 海沿いの章は、旅が本当に始まった証拠。山道の緊張がほぐれ、四人が自分たちのリズムで動き始める。

※ キャミィがアクセルを開けるたびにティファが笑うのは、いつもと逆の構図——ティファが表現し、キャミィが反応する。

※ ダンの「一枚だけ」は、この旅で一番正直な言葉かもしれない。
